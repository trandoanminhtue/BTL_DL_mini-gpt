\begin{abstract}
This milestone reports the implemented pipeline: shared Vietnamese BPE tokenizer, interpolated trigram and LSTM baselines, and a from-scratch Mini-GPT. Code and configs are complete; neural weights are trained on the full Wikipedia subset as compute allows. We record environment checks, parameter counts, and any numbers obtained by week 3. Empty metric cells mean training is not finished---they must not be filled with invented values.
\end{abstract}

\section{Status versus proposal}

The repository implements the design in the week-1 proposal: YAML configs, packed LM datasets, causal Transformer, LSTM, n-gram, perplexity scripts, and sampling. Week-3 deliverable is a runnable method, not a fully converged 30M model.

\section{Implementation}

\paragraph{Tokenizer.} Byte-level BPE, NFC normalization (diacritics kept), vocab size 16k.

\paragraph{Mini-GPT.} GPT-2-style decoder: $d$ residual blocks, causal attention (PyTorch SDPA when available), GELU MLP, tied input/output embeddings. Parameter counts from \texttt{scripts/check\_env.py}:

\paragraph{Training.} AdamW with decoupled decay on 2D weights, cosine LR, grad clip 1.0, AMP on CUDA. Checkpoints: \texttt{checkpoints/<run>/best.pt} (neural) or \texttt{best.json} (n-gram).

\paragraph{Baselines.} Trigram with interpolation $\lambda=(0.1,0.3,0.6)$. LSTM: 2 layers, hidden 512, tied embeddings.
